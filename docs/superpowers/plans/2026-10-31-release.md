# イロナラベ GitHub Pages移行 実装計画

**Goal:** 既存8ステージ版と記録の互換性を維持し、15言語・5効果音を追加して2つのPRを用意する。
**Architecture:** 既存inlineゲームを保ち、同一公開先の翻訳・音声JSを分離する。公開物はallowlistで生成し、既定ブランチpushだけGitHub Pagesへ配備する。
**Tech Stack:** Vanilla JavaScript, Web Audio, Node tests, Playwright Chromium/WebKit, GitHub Actions.
**Spec:** 利用者の2026-10-31実装依頼。具体的な実装・2PR作成まで許可済みのため追加の設計承認待ちは設けない。

## 制約
- default branch変更、直接push、merge、force push、branch削除を行わない。
- game_slug=ironarabe, score_order=asc, score_scale=100, score_decimals=2を維持。
- challenge ID、board version、seed、stage ID、送受信payloadを維持。
- 本番テスト送信なし。新URL公開確認前に実験場merge・DB更新なし。
